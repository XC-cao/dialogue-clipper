# Chrome Web Store 上架文案

## 名称

对话摘录 Dialogue Clipper

## 简短说明

从 ChatGPT、Claude 和 Gemini 摘录原文，用对话图与摘录图导航长对话，并导出 Markdown；所有数据只在本机。

## 详细说明

对话摘录帮助重度 AI 用户把散落在多轮对话中的关键片段整理成自己的证据型笔记。选中文字即可摘录，在侧栏添加批注、排序和更改高亮颜色，最后复制或下载标准 Markdown。

侧栏提供两种互相连接的导航：对话图展示网页当前可见路径上的“我 / AI”消息，支持搜索、阅读位置跟随和单击跳回；摘录图只呈现你主动保存的重点，支持自由连接和整理。对话节点可查看关联摘录，摘录节点也能反向回到对话位置。

它不会总结或改写原文，不需要账号，不上传内容，也不收集遥测。支持 ChatGPT、Claude 和 Gemini。页面改版导致高亮无法恢复时，原始摘录仍安全保留，并清楚显示定位状态。

## 单一用途

让用户导航支持的 AI 对话，主动摘录文字、添加本地批注并导出 Markdown 笔记。

## 权限披露

见 `PRIVACY.md`。商店问卷应选择不收集用户数据；发布前需按 Chrome Web Store 当期表单再次核对。
