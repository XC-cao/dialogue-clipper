# Chrome Web Store localized listing

This file contains the nine Store listing variants for the locales shipped in the extension package:

- `en` — English
- `zh_CN` — Chinese (China)
- `ja` — Japanese
- `ko` — Korean
- `pt_BR` — Portuguese (Brazil)
- `es` — Spanish
- `es_419` — Spanish (Latin America and Caribbean)
- `de` — German
- `fr` — French

In the Chrome Web Store Developer Dashboard, add each locale under Store listing and paste the matching name, short description, and detailed description. The locale code must correspond to a directory under `public/_locales/`. The small promotional tile is shared across locales; use the existing graphic-first asset because Chrome Web Store promotional images are not localized.

## English (`en`)

### Name

Dialogue Clipper

### Short description

Save key passages from ChatGPT, Claude, and Gemini, map long conversations, and export traceable Markdown notes.

### Detailed description

Dialogue Clipper helps you navigate long AI conversations, save the passages you choose, add local annotations, and export Markdown notes with their original sources.

AI conversations can be long, but the most useful evidence is often only a few lines.

With Dialogue Clipper you can:

- Select text in a supported conversation and save the original passage with your own annotation.
- Use a conversation map to revisit the visible path of a long conversation.
- Organize saved passages in a freeform clip map and connect related ideas.
- Jump from a clip back to its source message and highlight the saved text when it is available.
- Copy or download a notebook as a Markdown file for your existing workflow.

The extension is local-first. It does not summarize or rewrite your text, and it does not upload your conversations. The currently visible conversation path is processed temporarily in the browser; only passages you explicitly clip, your annotations, notebook information, and source links are saved in Chrome local storage.

Dialogue Clipper is independent and is not affiliated with or endorsed by OpenAI, Anthropic, or Google.

Privacy policy: https://github.com/XC-cao/dialogue-clipper/blob/main/PRIVACY.md

## 日本語 (`ja`)

対話クリッパー Dialogue Clipper

ChatGPT、Claude、Gemini の重要な原文を保存し、長い対話を整理して、出典付き Markdown ノートを書き出します。

### 詳細な説明

対話クリッパー Dialogue Clipper は、長い AI 対話をナビゲートし、選択した原文を保存して注釈を加え、元の出典付き Markdown ノートとして書き出すための拡張機能です。

AI との対話は長くなりがちですが、あとから確認したい根拠は数行だけということもあります。

できること：

- 対応している対話でテキストを選択し、原文と自分の注釈を保存する。
- 対話マップで、ページに現在表示されている長い対話のパスを見返す。

- クリップから元のメッセージへ戻り、テキストを特定できる場合はハイライトを復元する。
- ノートブックを Markdown としてコピーまたはダウンロードする。

この拡張機能はローカル優先で動作します。テキストを要約・書き換えたり、対話をアップロードしたりしません。ページに現在表示されている対話のパスはブラウザのメモリ上で一時的に処理され、明示的にクリップした原文、注釈、ノートブック情報、出典リンクだけが Chrome のローカルストレージに保存されます。

対話クリッパーは独立した製品であり、OpenAI、Anthropic、Google とは提携・承認関係にありません。

## 한국어 (`ko`)

### 이름

대화 클리퍼 Dialogue Clipper

### 짧은 설명

ChatGPT, Claude, Gemini의 핵심 원문을 저장하고 긴 대화를 탐색하며 출처가 포함된 Markdown 노트로 내보냅니다.

### 자세한 설명

대화 클리퍼 Dialogue Clipper는 긴 AI 대화를 탐색하고, 직접 선택한 원문을 저장하고, 주석을 추가하고, 원본 출처가 포함된 Markdown 노트로 내보낼 수 있도록 도와줍니다.

AI 대화는 길어질 수 있지만 나중에 다시 확인할 가치가 있는 근거는 몇 줄뿐인 경우가 많습니다.

다음과 같이 사용할 수 있습니다.

- 지원되는 대화에서 텍스트를 선택하고 원문과 내 주석을 저장합니다.
- 대화 맵으로 긴 대화에서 현재 페이지에 표시된 경로를 다시 확인합니다.
- 자유 배치 클립 맵에서 저장한 내용을 정리하고 관련 아이디어를 연결합니다.
- 클립에서 원본 메시지로 이동하고, 원문을 찾을 수 있으면 강조 표시를 복원합니다.
- 노트북을 Markdown 파일로 복사하거나 다운로드합니다.

이 확장 프로그램은 로컬 우선으로 작동합니다. 텍스트를 요약하거나 다시 작성하지 않으며 대화를 업로드하지도 않습니다. 현재 페이지에 표시된 대화 경로는 브라우저 메모리에서 임시로 처리되고, 직접 클립한 원문, 주석, 노트북 정보, 출처 링크만 Chrome 로컬 저장소에 저장됩니다.

대화 클리퍼는 독립적인 제품이며 OpenAI, Anthropic, Google과 제휴하거나 해당 업체의 승인을 받지 않았습니다.

개인정보처리방침: https://github.com/XC-cao/dialogue-clipper/blob/main/PRIVACY.md
