# Chrome Web Store screenshots

All files are 1280 × 800 PNG exports with editable SVG sources.

1. `01-capture.png` — selection, floating capture action, and saved clip.
2. `02-notebook.png` — a local notebook with sanitized ChatGPT, Claude, and Gemini example clips.
3. `03-conversation-map.png` — conversation search, active reading position, and source navigation.
4. `04-clip-map-export.png` — clip relationships and Markdown export.

The copy is deterministic and contains no real user conversation content. The interface composition is based on the production side panel, current feature set, and color tokens in `entrypoints/sidepanel/styles.css`. SVG is the editable source of truth; PNG is the upload artifact.
